# 需求与验收基线

## 用户、目标与范围

面向短视频创作者，按主题、受众、平台、目标时长、风格生成可以编辑和拍摄的脚本。必须同时保证文案完整、产品事实可追溯、时长达标；一句“支持字幕”不能算完整的30秒脚本。

采用 Python CLI、原生模型工具循环和本地合成素材。界面、部署、多 Agent、音视频生成不在当前范围。Mock 验证流程，真实模型记录验证模型对工具反馈的动作调整，二者分开保存。

## 输入输出

输入为 topic、audience、platform、target_duration_seconds、style，见 [schema](../schemas/input.schema.json)。五项业务必填，但允许接收缺字段/null/空白并请求补充；非法类型、未知字段和非正时长由 CLI 拒绝。

输出见 [schema](../schemas/output.schema.json)：status、message、missing_fields、自然语言 questions、script、顶层去重 source_ids、checks、risks、tool_calls_used。

脚本包含标题、版本、分镜、总时长；每镜包含画面、旁白、字幕、预计时长、claims。claims 包含 text、source_id、fact_id。顶层 source_ids 从最终输出脚本的分镜声明去重产生，失败且无可输出草稿时为 []。

## 事实与叙事

合成资料 P01 仅含 P01-F1“支持字幕”。带声明的产品事实必须对应资料原文、引用存在且出现在所属分镜；每个涉及该事实的分镜须有自己的引用，标题引用可由分镜提供。

开场提问、创作者情境、过渡、拍摄建议、互动收尾等非产品事实叙事允许自由创作，无需伪造引用。其余文本扫描能力、效果、数字、比较和绝对化信号；合法引用不能替额外的“自动生成字幕”“效率提升80%”背书。检测覆盖标题、画面、旁白、字幕。

词法检测不是语义证明，可能漏检或误报；成功文案仍需人工核对。不得描绘资料未支持的具体产品界面、按钮或操作流程。

## 时长与完成门禁

目标时长按区间解释：下限为目标的三分之二，向上取一位小数，上限为目标本身；30秒即20–30秒。估时不采信模型填写值，逐镜估算后求和，返回 too_long / too_short / within_range。

完成要求：输入完整、当前草稿的时长/事实/品牌检查通过、引用来自本轮实际检索，且检查哈希对应最终草稿。正文变化须递增版本并使旧检查失效。达到10次工具调用或12轮决策上限时明确未完成。单请求超时默认45秒，可配置至60秒。

## 状态

| 状态 | 含义 |
| --- | --- |
| completed | 当前版本满足全部交付门禁 |
| needs_input | 缺业务信息或需补充资料，必须给出用户可理解的问句 |
| insufficient_material | 当前资料不能支持主题，不编造产品事实 |
| tool_error | 工具或模型服务失败，无法继续完成 |
| constraints_unsatisfied | 已尝试调整仍未满足约束，说明未满足项 |
| step_limit_reached | 预算耗尽，任务未完成 |

未完成可保留已有估时草稿，但不能标为可交付成稿。仅有规则结果、没有有效估时的草稿不作为最终脚本输出。

## 验收

| ID | 条件与证据 |
| --- | --- |
| A01 正常 | 普通30秒输入，20–30秒、多分镜、受众/平台/风格可辨、P01引用、顶层来源、当前版本检查通过 |
| A02 缺信息 | 删除目标时长，中文询问实际缺失内容，不能仅返回字段名 |
| A03 无素材 | 空检索后由模型选择改写或请求补充，不编造资料 |
| A04 工具失败 | 结构化错误进入观察，模型决定重试或明确失败；恢复后重新检查 |
| A05 超时修正 | 普通30秒请求、无预设分镜或修正指令；真实 too_long 反馈后改稿再次估时，成功或明确未完成；不得伪造自然修正记录 |
| A06 上限 | 工具或模型轮数耗尽时停止并返回未完成 |
| A07 动态对照 | 比较正常、错误及不同检查结果下的模型后续动作，至少两条真实路径 |
| A08 事实 | 允许非事实叙事；拒绝无引用的能力/效果和合法引用之外的额外宣传 |
| A09 版本 | 修改后失效旧检查，最终估时、规则和输出一致 |

每组保存输入、实际输出、Trace，记录步骤、工具参数、结果、公开依据、下一动作；不记录模型内部思维过程。实际范围和未完成部分以 [评估报告](03-evaluation.md)为准。
